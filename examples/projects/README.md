# Example Projects

These projects are ready to load in the GUI and are intended as practical starting points.
All of them are composed from the curated factory patch library (`patches/factory/`) and
are regenerated by `examples/scripts/generate_example_projects.py`:

```bash
PYTHONPATH=python python3 examples/scripts/generate_example_projects.py
```

## Included Projects

- `darkwave_foundation.arachno`
  - Cathedral-dark darkwave in D minor (118 BPM): driving mono bass, night-choir pads,
    909/808 kit, dark arp walk, gliding mono lead, and a strings break. i-VI-III-VII.
- `factory_pulse.arachno`
  - Relentless EBM body music in A minor (130 BPM): sequenced industrial mono bass,
    iron kick, gated steel snare, euclidean anvil rim, body stabs, acid sequence, risers.
- `night_drive.arachno`
  - Rain-on-chrome melodic darkwave in F# minor (96 BPM): 808 groove, sub bass with
    legato glide, FM electric piano, warm analog pad, glass bells, portamento solo lead.
- `ebm_percussion_lab.arachno`
  - Drum-first laboratory (126 BPM): layered 808/909 kit, metal percussion, euclidean
    shaker/rim patterns, tom fills, retrigs and probability — a study project for the
    drum engine.
- `cinematic_darkwave_builder.arachno`
  - Slow-burn gothic score in C minor (72 BPM): low drones, cathedral choir, chamber
    strings, glass bells, ritual toms, impacts, wind/sweeps, and a violin aria climax.
    Long-form tension template (intro → build → climax → aftermath).
- `rust_belt_industrial.arachno`
  - Aggro-industrial machine music in G minor (140 BPM): crusher reese bass, zap snare,
    metal strikes, sync-scream lead, body stabs, radio static and alarm FX.
- `composition_starter_blank.arachno`
  - Blank composition canvas with the curated instrument/patch bank already loaded.

## Open In GUI

```bash
./build/ArachnoTracker --gui examples/projects/darkwave_foundation.arachno
./build/ArachnoTracker --gui examples/projects/factory_pulse.arachno
./build/ArachnoTracker --gui examples/projects/night_drive.arachno
./build/ArachnoTracker --gui examples/projects/ebm_percussion_lab.arachno
./build/ArachnoTracker --gui examples/projects/cinematic_darkwave_builder.arachno
./build/ArachnoTracker --gui examples/projects/rust_belt_industrial.arachno
./build/ArachnoTracker --gui examples/projects/composition_starter_blank.arachno
```

## Render To WAV

```bash
./build/ArachnoTracker --render examples/projects/darkwave_foundation.arachno /tmp/darkwave.wav
```
